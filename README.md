# 像素小镇 · 桌面悬浮小窗

一座漂在桌面上的像素小岛。你几乎什么都不用做，看着它慢慢长大就好。

- 开局是一座小岛、一条主街、四栋公共建筑和一户人家
- 之后**每过一个游戏日推进两次变化**：圈出一块新宅基地 → 盖房 → 翻新
- 新房子盖好就搬来新住户，人多了广场上就热闹起来
- 关掉它，小镇也会继续过；下次打开会告诉你"你不在的时候发生了什么"

---

## 怎么打开

**桌面上已经有一个「像素小镇」快捷方式**，双击它就行（图标是手绘的红顶小屋）。

也可以直接双击 **`启动小镇.vbs`**，同样不会有黑色控制台窗口闪出来。

如果双击没反应，改用 **`启动小镇-调试.bat`**，报错信息会留在屏幕上。

快捷方式指向 `wscript.exe` + 本目录的 `启动小镇.vbs`，图标用本目录的
`pixeltown.ico`。想重建图标就运行 `python tools/make_icon.py`。

关掉小镇的三种方式：

1. 在小镇上点右键 → **退出小镇**（会先自动存档）
2. 双击 **`停止小镇.bat`**
3. 任务管理器结束那个 python/pythonw 进程（会丢掉上次自动存档之后的进度）

`停止小镇.bat` 走的是**优雅退出**：它放一个 `save/stop.flag` 信号，
程序收到后自己存档再关闭。这比 `taskkill` 强杀好 —— 强杀会丢掉
最后一次自动存档之后的进度，而且现实中还常被杀软或权限拦下来。
万一 20 秒内没退掉，它才会退回强杀。

窗口位置会自动记住，下次打开还在原来的地方。

## 怎么玩

基本上只需要看。

| 操作 | 效果 |
|---|---|
| 按住左键拖动 | 把小镇挪到桌面任意位置 |
| 左键点村民 | 弹出他的档案卡：职业、心情、精力、饱腹、和谁关系最好 |
| 左键点空地 | 冒一颗小爱心 |
| 右键 | 菜单：暂停 / 时间流速 / 缩放 / 置顶 / 鼠标穿透 / 日志 / 退出 |
| 滚轮 | 缩放（2x / 3x / 4x） |
| Esc | 收起档案卡 |

### 鼠标穿透

右键菜单里的「鼠标穿透」打开后，小镇就不再拦截任何鼠标点击，
你可以正常点它下面的桌面图标。

穿透状态下一角会出现一枚**小圆把手**：那是唯一的退路 ——
点它一下就退出穿透模式。没有这个把手，穿透就是不可恢复的状态，
所以它不会省掉。

## 它会自己发生的事

**一天的样子**（1 个游戏日 ≈ 6 分钟真实时间）

| 游戏时间 | 小镇在做什么 |
|---|---|
| 00:00–06:00 | 全镇睡觉，只有路灯亮着、窗户透出暖光 |
| 06:00–07:00 | 陆续出门 |
| 07:00–12:00 | 工作（农夫去地里、渔夫去码头、铁匠在铺子） |
| 12:00–13:00 | 午休，聚到井边 |
| 13:00–17:30 | 继续工作 |
| 17:30–19:00 | 自由活动，有人坐长椅 |
| 19:00–21:30 | 广场社交 —— 关系在这里升温 |
| 21:30– | 各自回家 |

**关系**会从点头之交一路长到朋友、挚友。
升温的时候两人头顶会冒爱心，日志里也会留一句话。

**季节**每 7 个游戏日换一次：春天的嫩绿、夏天的深绿、秋天的黄叶、冬天的雪。
树冠颜色、草地、水面都会跟着变。

**天气**每天随机：晴、多云、雨、雪。下雨时画面会压暗。

**农田**里的庄稼会自己长，熟透了会有一片金黄，然后被收掉重种。

## 广场正中的喷泉

小镇的地标：主街正中那块广场，几何中心上立着一眼喷泉。

- 上下两层水池 + 中间石柱，20×18 像素，手写 ASCII 一次定死比例
- 水柱 4 帧循环（柱高来回变，两侧水珠逐帧下落），池面还有两点波光来回晃
- 喷泉和村民走**同一个 y 排序**，站在它前面的人会自然挡住它，而不是糊在喷泉上
- **水池不站人**：傍晚大家聚到广场时是贴着喷泉围一圈，而不是站进水里
- 主街仍然贯通：只封水池那一行，从西头走到东头不受影响

换 seed 重开一座小镇，喷泉依然在广场正中 —— 这一条由 `tools/validate_world.py`
的 8 条断言盯着（居中 / 全落在广场上 / 不压别的道具 / 水池不可站 / 主街不断 /
四周还能站人）。

## 村民记得住事（记忆流）

以前村民只活在"此刻"：他只知道现在几点、天气、自己在干嘛。
所以同一个村民每一天开口都像刚出生的 —— 说不出一件昨天的事。

现在每个村民有自己的**记忆流**，24 条上限，带时间戳：

- **与他有关的事**才记：和谁成了朋友、和谁聊过几句、今天什么节日、镇上哪栋房子变了样、自己说过什么
- **检索**不是取最近几条，而是打分：新近性（3 天半衰） × 相关性（关系 > 对话 > 事件 > 闲事） × 一点点个体抖动
- **反思**：同类记忆攒到 3 条，压成一句自我认知（"看着小镇一点点变样：…"），进人设里
- 记忆**存进存档**，读档不失忆

最要紧的一条约束是**不许全镇长成同一份镇志**：

```
记忆是个人化的（不是全镇一份）  12 人 -> 12 种组合
```

这条现在由自检盯着。早期版本把"镇上在变"广播给所有人，结果十二个村民
的记忆一模一样，检索出来的话也一模一样 —— 那不是记忆，那是复读机。
所以：广播类记忆只写给**当时在外面看得见**的人，淘汰时也先丢广播类
（`move/event`），把 `rel/talk` 这些"只有我记得"的私人历史留到最后。

检索刻意做得很"笨"（纯算术，不用 embedding）：它必须在断网、没模型的时候也算得出来。

## 陪着你上班（外部活动映射）

小镇原本是个封闭的模拟，跟你桌上这台机器毫无关系。
现在它会读一点真实世界的动静：

| 信号 | 小镇的反应 |
|---|---|
| CPU 占用高 | 干活的工匠（铁匠/木匠/织工/农夫/渔夫）说一句"活儿多" |
| `save/activity.txt` 有内容 | 立刻算作忙，那行字会变成台词里的"今天在忙什么" |
| 什么都没有 | 什么都不发生，和以前一模一样 |

自己接一下也很容易，比如在构建脚本里：

```bat
echo 正在编译 > save\activity.txt
```

几条刻意的设计：

- **不暴露"我在看你的 CPU"**。台词说的是"今天活儿多"，不是"你占用率 78%"——
  不然小镇就变成监控软件了。
- **不改变作息表**。机器再忙，农民也不会半夜下地。小镇的节奏不该被占用率绑架。
- **标记立即生效，不等平滑爬坡**。标记是你主动写的，等两秒才反应过来就没意义了。
- **过期标记自动忽略**（5 分钟），否则一个忘了删的文件会让小镇永远加班。
- **可以完全关掉**。右键菜单 →「外部活动」，关掉之后一个字节都不读。

采样只用标准库：Windows 走 `GetSystemTimes`，其他平台读 `/proc/stat`，
**不依赖 psutil**。采样在后台线程，主循环只读一个算好的快照 ——
和 AI 那边是同一套哲学：绝不阻塞渲染。

## 换一座小镇（存档管理）

以前想换一座镇子，只能自己去删 `save/town.json`。删错了就没了，
而且不知道有哪些可选。现在右键菜单里多了「我的小镇」：

```
✓ 春天的小镇 · 第12天 · 9人 · 夏
  夏天的小镇 · 第31天 · 12人 · 秋
  ─────────────
  新开一座小镇…
  备份当前小镇
```

- **新建**：随机 seed，自动命名（`小镇-483920`），不动当前存档
- **切换**：当前那座会**先保存再备份**，然后才被替换
- **备份**：一键快照，只留最近 12 份，不会把目录撑爆
- **删档走回收站**：移到 `save/trash/`，不是真删，能捞回来
- 名字做了过滤：`../../evil` 这类穿不出 `towns/` 目录

目录长这样：

```
save/
├─ town.json          当前小镇
├─ towns/             所有备选小镇（模板）
├─ backups/           自动 + 手动快照
├─ trash/             删掉的小镇（可恢复）
└─ activity.txt       可选：写一行字让小镇"忙起来"
```

切换之后需要重启窗口 —— 地块、人头、记忆全要从新档重建，
热替换的路径太多，不值得。

## 人口有进有出

小镇**不是只涨不跌**的。住得下多少人由民宅数量决定：

```
容量 = 4 个公共岗位（镇长/店主/铁匠/农夫）+ 每盖好一栋民居 1 个位子
硬上限 12 人，下限 4 人
```

有空位就会有人搬来；住满了则偶尔有人搬走，腾出位子后又会来新人。
实测 40 个游戏日：搬入 6 次、搬出 4 次，人口在 6–12 之间起伏。

**搬走永远是"出去看看"，绝不是因为你冷落了谁**：

```
阿杏说要去城里学门新手艺，收拾了行李走了
大家在路口站了一会儿，看着阿杏走远
```

走之前还会留句温暖的话（把花分给邻居、把钥匙交给隔壁）。
关系最好的人会到路口送一送，头顶冒一颗心。
搬走的人会从他的关系表里清干净，不会在存档里留下幽灵。

职业也从 7 种扩到 12 种：镇长 / 店主 / 铁匠 / 农夫 / 渔夫 / 木匠 / 牧人 /
织工 / 货郎 / 采药人 / 孩子 / 村民。新来的人**优先填还没人干的岗位**，
全部填满后才做普通村民。没有专属建筑的职业各有去处：牧人去田里、
织工在家、渔夫去码头、货郎和采药人四处走。

另外，镇上**总会留着至少一个孩子** —— 没有孩子的小镇不像小镇。

## 节日

每个季节的**第 4 天**办一次节，四季节日各不相同：

| 季节 | 节日 | 场面 |
|---|---|---|
| 春 | 花朝节 | 树上系彩带，孩子们把花戴在头上 |
| 夏 | 河灯节 | 水面上漂着一盏盏小灯 |
| 秋 | 丰收祭 | 谷仓前堆满新粮，广场上拼起长桌 |
| 冬 | 灯会 | 街上挂满灯笼，雪地被照得暖暖的 |

节日当天**全镇停工**：早上在家吃饭 → 上午到广场 → 中午会餐 → 下午继续聚着 →
晚上夜市，一直待到散场。关系在节日里升温更快。街上挂灯笼、广场拉彩旗，
白天夜里都在飘季节彩屑（春花瓣 / 夏黄点 / 秋落叶 / 冬雪）。

节日是**无状态算出来的**（由日期直接推），不进存档，所以读档和离线补算都不会算错。

## 随机小事与动物迁徙

每天有 42% 的概率发生一件小事，**全是好事或者无所谓的事，没有一件是坏的**：

| 日志 | 画面上能看到 |
|---|---|
| 有只野猫溜进了小镇，蹲在井边不肯走 | 井边真的蹲着一只猫 |
| 外乡的货郎来了，在广场摆了半天的摊 | 广场上摆出两个摊位 |
| 有人过生日，广场上分了点心 | 天上下彩屑 |
| 雨后挂起了一道彩虹，横跨整个小镇 | 一道真的彩虹 |
| 早上起了雾，房子像是浮着的 | 整幅画面罩上一层雾 |
| 夜里有人看见流星，许了愿 | 四道流星划过 |
| 一群鸭子摇摇摆摆地穿过了大街 | 鸭子横穿主街 |

同一件小事**至少隔 4 天才可能再出现**，否则会出现"野猫连着两天溜进小镇"。

**动物迁徙**按季节换主角：

```
春天  一大群蝴蝶从镇子上头飞过去了
夏天  蜻蜓成群地掠过水面
秋天  大雁排成人字，往南边去了
冬天  一群白鸟顶着雪往北边飞
```

一队动物会真的从画面一侧飞到另一侧（大雁是 V 字队形并扇翅膀），
之后日志补一句「孩子们追着跑了一段，没追上」。

## AI 村民（接入本地大模型）

村民可以不按固定台词说话，而是由你**本机的 Ollama** 现场生成。

```bash
# 先确保 Ollama 在跑
ollama serve
# 模型（已经在你的 D:\llm\ollama-models 里）
ollama list     # qwen3.5:9b / glm-4.7-flash:latest / qwen3-embedding:0.6b
```

默认就用 **qwen3.5:9b**。右键小镇 → 菜单里有一项「AI 村民：已连接」，
点一下就能开/关。顶部信息牌上也会显示当前状态。

它做三件事：

1. **自己说话** —— 每隔约 2.4 个游戏小时，挑一个在场的村民，让他说一句。
   台词是根据他**当时的真实状态**生成的：几点、什么天气、在干什么、
   身体什么感觉、身边有谁、注意到什么小东西、最近镇上发生了什么。
2. **自己做小决定** —— 傍晚 17:30–19:00 那段空闲时间，由模型在
   **几个合法选项**里挑一个去哪（走走 / 找人聊天 / 回家歇着 / 吃点东西，
   农夫多一个"去田里"，渔夫多一个"去码头"，孩子多一个"去玩"）。
   注意：**作息表本身没被打破**，他仍然是"空闲"，只是往哪边走由模型定。
3. **每天一条旁白** —— 把当天真实发生的事交给模型，写成一句话。

### 十种说话风格轮换

只给一句"说得好笑点"，模型会连着吐同一类句子，看两天就腻。
所以拆成十种互不相同的具体手法，**每次随机挑一种**：

| 风格 | 真实产出 |
|---|---|
| 平常 | 这光忽明忽暗的，正好省了灯钱！ |
| **语序颠倒** | 我饭吃得今天很饱。 |
| 一本正经说废话 | 手里的锤声和青草的味道一样新鲜。 |
| 童言无忌 | 铁锤打下去的时候，树芽也在跟我握手呢！ |
| 小题大做 | 这春风一吹，我的鱼竿都得往后缩三尺！ |
| 自我吐槽 | 刚给花坛松土，差点把自己埋进春天里去了。 |
| 拟声词 | 哗啦——这井水比我的干劲还冲！ |
| 突然哲学 | 这块石头的脾气倒是不小，还挺硬气。 |
| 强行押韵 | 铁锤敲得叮当响，风里全是青草香。 |
| 答非所问 | 那只麻雀咋不进来吃鱼呢？我锅里还有两条！ |

旁白也有三种语气，其中最放得开的是这种：

> （旁白）春日暖阳下有人忙着量地建新屋，看来铁匠的翻新工程终于能住进去了。
> 真是热闹得像个刚拆封的新玩具盒！
> （旁白）云朵懒洋洋地挂着，有人忙着丈量未来，顺便把日子也扩建得宽敞起来啦。

右键菜单里的「AI 搞怪程度」有三档：**正经**（只保留平常语气）/
**温和** / **搞怪**（默认，十种全开）。想看看每种风格长什么样：

```bash
python tools/taste_test.py --per 4      # 每种采样 4 条打出来
python tools/taste_test.py --style scramble   # 只看某一种
```

### 几条工程上的硬约束

- **绝不阻塞渲染**。首次调用要加载权重（实测 qwen3.5:9b 约 **59 秒**），
  这要是跑在主线程上小镇会直接卡死。所以是后台线程 + 双向队列：
  提交立刻返回，主循环每帧收一次结果。
- **连不上就静默降级**。Ollama 没开、模型没拉、端口不对 —— 村民改说内置台词，
  小镇照常运转，不弹窗不报错。状态会显示成「AI 连不上」。
- **排队满了就丢旧的**。半分钟前的一句台词塞到现在只会显得莫名其妙，
  所以宁可丢掉。
- **情境变了就丢弃**。请求回来时如果他已经进屋、或者换了活动，
  这条台词就不要了。
- **按职业收窄选项**。不收窄的话实测会出现"铁匠跑去种地"，
  而且三个人同时选同一个 —— 因为提示词几乎一样。
- **得给模型"抓手"**。persona 里塞一个随机小细节（"路边有只蚂蚁在搬东西"
  "井边的水声很响"），台词才不会条条都长一个样。
- **必须压住客服腔**。不写"你不是在回答用户"，模型会张口就是
  "你好，有什么可以帮你的吗"。
- **例子必须换行、不能有星号**。糊成一整行模型会当成乱码；
  markdown 的 `*` 会被原样抄进台词里。
- **输出要洗**。小模型很爱加引号、加换行、"好的，作为……"，
  这些在 8×12 像素的对话框里全是灾难，统一在这里掐掉。
- **静默失败最要命**。所以有 `ai_diag` 计数器（说了几句 / 决策落地几次 /
  被拒几次 / 旁白几条）和 `ai_raw` 原始输出留存，都写进存档。
  开发过程中正是靠它定位到"决策一条都没生效"和"补算期间旁白被整批跳过"。

想换模型：改 `save/settings.json` 里的 `ai_model`，或者改
`town/llm.py` 的 `DEFAULT_MODEL`。

## 它不会发生的事

这是刻意设计的：

- **没有饥饿惩罚**。需求只影响表情和心情，不会饿死、不会生病、不会有任何损失
- **你不在的时候不会出事**。离线补算最多 3 个游戏日，回来只会看到"变多了"
- **没有任务、没有金币、没有要你点的地方**
- **AI 不会接管小镇**。作息表、成长节奏、季节全都不受模型影响 ——
  它只负责说话和"往哪边走"这种小选择，而且只能在给定选项里挑。
  Ollama 关掉，小镇一模一样地运转。

忘了打开它几个星期，回来它还是好好的，只是长大了一些。

`validate_interaction.py` 会真的建一个 Tk 窗口（用 alpha≈0.02 藏起来），
然后把合成事件喂给 app.py 里真实的事件处理函数。所以"点村民有没有选中"

### 几个刻意踩过的坑

- **透明键必须精确**。`#FF00FF` 是抠图键，昼夜染色会污染它，
  所以遮罩裁切放在所有绘制之后，保证边缘像素严格等于键色。
- **UI 要在放大之后画**，否则中文会糊；但又要被岛屿剪影裁切，
  看起来才像"嵌在岛上"而不是在透明区糊出一块矩形。
- **进程必须声明 DPI 感知**。否则 Windows 会按 125% / 150% 非整数缩放，
  像素画会被双线性插值糊掉 —— 这是像素风应用最致命的问题。
- **鼠标穿透必须留退路**，否则窗口既不能点也不能关。
- **`.vbs` 必须存成 UTF-16LE + BOM**。WSH 默认按 ANSI(GBK) 读脚本，
  UTF-8 的中文字节会被当成 GBK 双字节、把后面的引号一起吞掉，
  直接报 `Unterminated string constant` 编译错误。
- **`.bat` 必须用 CRLF 换行**。LF-only 的批处理里 `goto 标签` 会解析失败
  （报 `The system cannot find the batch label specified`）。
- **别用 `timeout` 做批处理延时**：stdin 被重定向时它会直接失败，
  用 `ping -n 2 127.0.0.1 >nul` 才稳。
- **停止用优雅退出而不是 `taskkill`**：强杀会丢掉最后一次自动存档之后的进度。
- **AI 相关的东西全部是异步的**。首次调用要加载权重（实测 59 秒），
  任何一处同步等待都会让小镇卡死。所以请求走队列、结果每帧收一次。
- **别把字符串常量当条件**。`if "mist":` 在 Python 里恒为真，  于是只要特效表非空就会把雾糊满整幅画面 —— 不报错、不崩溃，
  只是画面悄悄变亮。是"特效颜色数从 440 跳到 1670"这个异常把它揪出来的。
  现在 `render_shots.py` 有一条 **FX LOCALITY** 检查专盯这个：
  加一个小特效，改动范围必须很小。
- **用 len() 当 id 迟早撞车**。`add_villager` 原来用 `len(self.villagers)` 当 vid，
  一旦有人搬走 len 就回退，新来的人会和存档里的老村民撞号 ——
  关系表、待回复集合全是按 vid 索引的，撞了就串味。
  现在用单调递增的 `_next_vid`，而且存档时会连它一起存。
- **接 AI 的代码必须"连不上也能用"**。降级路径要和正常路径一样常测，
  否则用户哪天没开 Ollama，得到的是一个坏掉的小镇而不是一个安静的小镇。
- **改了 `town/*.py` 必须重启进程才看得到**。桌面上的窗口是**启动那一刻**的代码，
  改完代码不重启，屏幕上还是旧的 —— 喷泉就是这么"写完却看不见"的：
  代码 17:27 改好，运行中的窗口是 14:37 启动的，中间差了三个小时。
  判断办法很简单：比对源文件的修改时间和 `save/app.pid` 里那个进程的启动时间。
- **断言别赌随机抽签**。迁徙是每天 11% 的随机事件，40 天里抽不到两次的概率约 5%，
  原来那条 `迁徙发生过 ≥ 2 次` 就是一颗定时炸弹：任何一个挪动 rng 序列的改动
  （哪怕只是让三个格子不可通行）都会让它无缘无故变红。现在验的是**机制**
  （把 rng 换成一定触发的桩，看迁徙会不会起来），自然抽签的结果只打出来看。
- **别拿可能为 None 的字段当字典键**。刚搬来的人在下一个 tick 之前
  `activity` 还是 `None`，`sorted(acts.items())` 会在 `None` 和 `str` 之间比较，
  直接把 `validate_sim.py` 整个炸掉 —— 而崩溃点离真正的成因隔着一整个采样循环。
  现在打印成 `未定=1`，反而把这件事看见了。
- **广播的记忆会养出复读机**。记忆流第一版把"镇上在变"写给所有人，
  结果 12 个村民的记忆一模一样，检索出来的台词也一模一样。
  记忆必须允许"我不知道这件事"，否则它就不是记忆，是镇志。
  现在广播类只写给当时在外面的人，淘汰时也先丢广播类。
- **改代码时别用"只给锚点"的方式替换函数头**。这次两次用编辑工具插新方法，
  把相邻的 `def toggle_pause(self):` 一起吞掉了 —— 语法照样合法（方法体变成了
  上一个方法的续行），`validate_art/world/sim/life` 也全都照过，
  只有真正调 GUI 的 `validate_interaction.py` 才会报
  `'TownApp' object has no attribute 'toggle_pause'`。
  所以：**改完 `app.py` 一定要跑一遍真实 GUI 自检**，它专门抓这类"静默的断手"。

## 已知限制

- 窗口是矩形的：岛的四个透明角仍然会拦住鼠标点击。
  想要完全不挡路，用右键菜单开「鼠标穿透」
- 离线补算上限 3 个游戏日，离开再久也只补这么多（避免一回来就沧海桑田）
- 村民只在镇上活动，不会走上海滩之外的区域
- 目前没有声音
- 画面好不好看这件事，程序断言只能保证"结构正确"（剪影完整、四角透明、
  昼夜亮度拉开、四季有差异），**顺不顺眼还得人来判断**
